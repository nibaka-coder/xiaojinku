## 步骤 5 · 安全验证（只读，不改数据）

```bash
curl -I https://xiaojinku.19950920.xyz/sync/data/xiaojinku.json
curl -sI -H 'Origin: https://evil.example.com' https://xiaojinku.19950920.xyz/sync/api.php | grep -i 'access-control-allow-origin'
```

**预期**：第一条 403（或 404）；第二条无输出。
**第一条返回 200** → 账本可被任何人下载，必须立刻补 nginx 规则：

```nginx
location ~* ^/sync/data/ { deny all; }
```
