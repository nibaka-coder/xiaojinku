# 小金库 · 自建服务器同步部署说明

把应用在手机和电脑之间打通：数据存在你自己的服务器上，两端自动同步。

---

## 一、服务端准备（宝塔）

### 1. 建站点
- 宝塔 → 网站 → 添加站点
- 类型选**纯静态**（不需要数据库、不需要 PHP 版本选择以外的东西）
- 域名建议用子域名，例如 `money.example.com`
- 根目录例如 `/www/wwwroot/money.example.com`

### 2. 申请 HTTPS（必做）
- 站点设置 → SSL → Let's Encrypt → 申请并开启**强制 HTTPS**
- 原因：手机「添加到主屏幕」、剪贴板等能力都要求 HTTPS；同时避免明文传输财务数据。

### 3. 上传同步接口
在站点根目录下建一个 `sync` 目录，把本文件同目录下的两个文件放进去：

```
/www/wwwroot/money.example.com/sync/api.php
/www/wwwroot/money.example.com/sync/.htaccess   （见下文，用于保护 data 目录）
```

然后把 `api.php` 上传到 `/sync/api.php`。

### 4. 创建数据目录与令牌
**推荐做法（数据放在站点外，最安全）**：

编辑 `api.php` 顶部这一行，把数据目录指到站点之外：

```php
const DATA_DIR = '/www/backup/xiaojinku-sync';
```

然后 SSH 或宝塔文件管理器执行：

```bash
mkdir -p /www/backup/xiaojinku-sync/history
# 写入你自己的令牌（一行，建议 20 位以上随机字符）
echo '你的自定义令牌' > /www/backup/xiaojinku-sync/token.txt
chmod 700 /www/backup/xiaojinku-sync
chmod 600 /www/backup/xiaojinku-sync/token.txt
```

**简化做法**：数据放在站点内 `sync/data`（脚本会自动建目录并写入保护文件），
仍需创建 `sync/data/token.txt` 写入令牌。站点内目录**必须**配合下面的 `.htaccess`。

### 5. 保护数据目录
若数据目录在站点内，在 `sync/data/.htaccess` 写入（脚本首次运行会自动创建）：

```
Require all denied
```

Nginx 用户请在站点的 Nginx 配置里加：

```nginx
location ~* ^/sync/data/ {
    deny all;
}
```

### 6. 建议加一层访问密码（可选）
宝塔 → 站点设置 → 目录保护 → 对 `/sync` 开启 Basic Auth。
虽然数据不在服务器上，但没必要让财务应用接口裸奔在公网被扫描。

## 二、应用内配置

1. 把 `xiaojinku-v2.19.html` 上传到站点根目录，改名 `index.html`（这样访问域名直接打开）。
2. 打开应用 → 设置 → **云同步**：
   - 接口地址：`https://money.example.com/sync/api.php`
   - 访问令牌：上一步 token.txt 里的那串字符
   - 打开「启用云同步」
3. 点「立即上传」，把当前数据作为初始版本推到服务器。
4. 在另一台设备（手机）打开同一地址，填同样的地址与令牌，点「立即下载」。

---

## 三、同步行为说明

- **本地优先**：数据先写本机 IndexedDB，离线照样记账，联网后再同步。
- **自动推送**：任何改动后约 2 秒自动上传（防抖，连续记账只推一次）。
- **自动拉取**：每次打开应用时自动拉取服务器数据。
- **冲突处理（重要）**：
  如果服务器上的数据比你这台设备已同步的版本更新，**不会静默覆盖**。
  应用会弹窗让你选择：
  - 「用服务器的」：本机数据被服务器数据替换
  - 「保留我的并覆盖服务器」：以本机为准，强制上传
  
  这样手机和电脑同时改了数据，也不会有一边的记录凭空消失。

- **历史快照**：服务端每天保留一份快照，最多 30 份（在 `history` 目录），误删可从中恢复。

## 四、常见问题

**Q：换了域名/从本地预览切到服务器后，数据不见了？**
这是正常的——浏览器数据按「协议+域名+端口」隔离。
正确顺序：先在原地址**导出 JSON** → 部署到新地址 → **导入 JSON**。

**Q：同步失败怎么办？**
依次检查：① 接口地址是否以 `https://` 开头且可访问；② 令牌是否与 token.txt 完全一致（注意别带换行）；
③ 服务器是否开了 HTTPS 且证书有效；④ 浏览器控制台是否有 CORS 报错（若报 CORS，说明 api.php 的 CORS 头没生效，检查 PHP 是否正常解析该文件）。

**Q：数据存在服务器上安全吗？**
数据以明文 JSON 存在你自己的服务器，不经过任何第三方。
传输走 HTTPS。配合目录保护 + 强令牌，对自用场景足够。
若特别在意，可在服务器上对数据目录做磁盘加密。

**Q：同步后还需要导出备份吗？**
建议保留。服务器硬盘也会坏，两边都留最稳。
应用会在概览页提示你超过 30 天未备份。
