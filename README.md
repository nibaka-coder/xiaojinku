# 小金库

一个本地优先的个人财务 Web 应用。记账、负债、净资产、投资持仓与已实现盈亏，全部数据存在你自己的浏览器里，不上传任何服务器。

产物位于 `app/dist/`：`index.html`（应用本体）+ `manifest.webmanifest` + `sw.js` + `icons/`。构建完成后即可作为 **PWA** 部署——安卓可直接「安装」，iPhone 可从主屏全屏打开并豁免 Safari 的 7 天数据清理策略，断网也能打开页面。

## 功能

- **概览**：净资产、本月收支（含环比）、本年累计、**近一年净资产走势**、投资情况概览
- **日常开销**：记账 / 流水 / 统计（收支趋势图、分类占比饼图、支出排行 TOP10）
- **投资管理**：持仓总览（实时行情、浮动盈亏、累计已实现盈亏）、交易记录（买卖批次配对算已实现盈亏）
- **设置**：资产负债总览、长期负债管理、分类管理、外观（浅/暗/跟随系统）、应用锁、汇率、**云同步**、数据导入导出

### 支出摊销

车险、年度会员这类一次性支出，可在记账时标记「按区间摊销」，填写起摊月与期数（如 12 个月）。统计口径下按 `总额 ÷ 期数` 分摊到各月（末月承担尾差，总额精确）。

现金余额与净资产仍按实际付款日与全额计算——钱确实当天出去了，账实能对上；摊销只影响成本归属的统计视图。

## 运行与构建

```bash
cd app
npm install
npm run dev     # 开发
npm run build   # 构建，产出 dist/（index.html + PWA 三件套 + 图标）
```

技术栈：Vite + React 18 + TypeScript + Tailwind CSS + Zustand（persist 到 IndexedDB）+ ECharts。

## 数据同步（可选）

默认纯本地。若想在手机与电脑间同步，可自建服务端：

1. 把 `app/deploy/api.php` 部署到你的服务器（PHP 单文件，无需数据库）
2. 创建 `token.txt` 写入自设令牌
3. 应用内「设置 → 云同步」填入接口地址与令牌

详见 `app/deploy/部署说明.md`（含宝塔面板的逐步操作）。

同步策略为**本地优先 + 整份 JSON + 版本号**：离线照样记账，联网后自动同步；两端同时改动时会弹窗让你选择保留哪一份，**绝不静默覆盖**。

## 数据备份

数据存在浏览器的 IndexedDB 中，换浏览器、清缓存、换设备都会丢失。请定期用「设置 → 导出 JSON」备份，并妥善保存（建议本地与云端各一份；JSON 为明文，含全部财务信息，存网盘前建议加密压缩）。

## 隐私

- 所有数据留在本地浏览器，应用本身不向任何第三方发送数据
- 行情来自公开的行情接口，汇率来自公开汇率接口
- 开启云同步后，数据只发往你自己配置的服务器

## 目录结构

```
app/
  src/            源码
  public/         PWA 资源（manifest.webmanifest、sw.js、图标）

  deploy/         自建同步服务端（api.php + 部署说明）
  dist/           构建产物（index.html + PWA 文件，随仓库发布，服务器 git pull 即得）
  verify_*.mjs    无头浏览器回归测试脚本

```
