## 二、设计原则（作为取舍依据）

1. **克制优先**：这是记账工具，动效服务于"理解发生了什么"，不服务于炫技。任何动效若不能传达状态变化，就不做。
2. **只动 transform / opacity**：禁止动画 `width/height/box-shadow/top/left`。移动端 + 单文件包背景下，这是红线和性能底线。
3. **移动优先，桌面不降级**：底栏、手势、安全区是主战场；桌面侧边栏同步受益，但不为桌面牺牲移动端。
4. **零新增重依赖**：不引入 framer-motion（约 50KB）。图标自研内联 SVG，动效用 CSS + 少量 hook。
5. **尊重系统设置**：`prefers-reduced-motion` 必须降级；暗色模式对比度 ≥ 4.5:1。
6. **一致性 > 个性**：全站同类交互用同一时长、同一曲线。建立 token，不写魔法数字。

## 三、设计系统层（先建地基，再改页面）

### 3.1 动效 Token

在 `index.css` 增加变量（JS 侧同步一份常量供内联样式用）：

```
--dur-fast:  120ms   /* 按压、hover 等即时反馈 */
--dur-base:  200ms   /* 状态切换、展开收起 */
--dur-slow:  280ms   /* 弹窗/抽屉/页面入场 */
--ease-out:   cubic-bezier(.2,.8,.2,1)     /* 默认，进场 */
--ease-in:    cubic-bezier(.4,0,1,1)       /* 退场 */
--ease-spring:cubic-bezier(.34,1.56,.64,1) /* 成功反馈、数字跳动 */
--stagger:   35ms    /* 列表错峰间隔，最多累计 8 项后不再延迟 */
```

语义类：`.anim-fade-up`（8px + opacity）、`.anim-pop`（scale .96→1）、`.anim-slide-up`（弹窗 24px）、`.anim-drawer`（抽屉 -100%→0）。

**红线**：单个动效 ≤ 300ms；入场可错峰，退场不错峰；任何动画不得阻塞点击（用 `pointer-events` 而非 `disabled` 时尤其注意）。

### 3.2 图标体系 ~~（本次最关键的视觉升级）~~ → **用户暂缓，暂不实施**

`src/components/Icon.tsx`：自研 SVG 图标组件，`stroke-based`、24 viewBox、`stroke-width 1.6`、`currentColor`、无填充。约 28–34 个图标，单文件构建增量估计 3–6KB（gzip 后），可接受。

**分三批替换：**

| 批次 | 图标 | 理由 |
|---|---|---|
| P0 必换 | 底栏 4 个（概览/日常/投资/设置）、顶栏汉堡 + 设置、导航 4 个、展开箭头 ▾/▸、关闭 ×、删除、编辑、返回 | 结构性图标，emoji 变形最明显，直接决定"精不精致" |
| P1 | 状态图标（成功/警告/错误/空态/同步中/锁定）、操作图标（刷新/导出/导入/筛选/搜索/日历/加减） | 语义明确，emoji 表达模糊 |
| P2 | 设置子项图标、分类默认图标兜底 | 锦上添花 |

**分类图标保留 emoji**（重要决策）：分类是用户自定义的、数量无上限、语义靠用户自己理解，做成 SVG 反而丢失表现力和可玩性。但要解决"冷僻 emoji 变豆腐块"的问题——做法：内置一份**精选 emoji 集**（约 60 个，覆盖餐饮交通购物居住医疗教育娱乐人情等），新增分类时从这个集里挑；对超出集合的存量数据保留原值，渲染时加 `font-family` 兜底。

### 3.3 空状态与加载态组件

- `<EmptyState icon title desc action>`：图标 + 主文案 + 一句引导 + 一个行动按钮（如"去记一笔 →"）。替换全站 `暂无持仓/暂无交易记录/该区间暂无支出记录` 等 6–8 处干瘪文案。
- ~~`<Skeleton>`~~ **用户暂缓**：灰条 + 微光扫过（`translateX` 位移实现，不用 width 动画）。原计划用于刷新行情/切月份/云同步，当前无痛感，暂不实施。

### 3.4 反馈层

- `<Toast>`：底部居中（避开底栏）、3 秒自动消失、支持一个操作按钮（承载"撤销"）、支持堆叠 ≤2 条。
- 全站 `window.confirm` 逐步替换为 `ConfirmDialog`（减少原生弹窗与自研弹窗并存的分裂感）。

## 九、明确不做

- 不引入 framer-motion 等动效库（体积代价不划算）
- 不做 3D、粒子、渐变流光等装饰性特效（与记账工具的克制调性冲突）
- 不重构数据模型与业务口径（净资产/配对/汇率逻辑本轮冻结）
- 不更换主色系（鼠尾草绿 + 奶油底已确认，只做深浅与对比度微调）
