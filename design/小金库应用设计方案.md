# 小金库 · 应用设计方案（初稿）

> 定位：个人财务管理中枢，围绕「钱从哪来、钱去哪了、钱生钱、为未来攒钱」四条主线，
> 划分为 **三个核心模块 + 一个总览仪表盘**。本文档为初步设想，供评审与迭代。

---

## 一、整体架构

```
                 ┌─────────────────────────────────────┐
                 │          总览仪表盘 Dashboard          │
                 │  净资产 · 本月收支 · 投资盈亏 · 目标进度 │
                 └─────────────────────────────────────┘
                    │              │              │
        ┌───────────┴──┐  ┌────────┴────────┐  ┌──┴───────────┐
        │  日常开销      │  │   投资（股票）     │  │   目标预算     │
        │  记账/分类/预算 │  │  A股 + 美股        │  │ 装修/旅行/购房 │
        │  收支报表      │  │  持仓/盈亏/分红    │  │ 进度/倒计时    │
        └───────────┬──┘  └────────┬────────┘  └──┬───────────┘
                    │              │              │
        ┌───────────────────────────────────────────────┐
        │   本地数据存储层（IndexedDB · JSON 导入/导出）    │

                          │ （可选）
        ┌───────────────────────────────────────────────┐
        │   行情数据：A股 东财/新浪 · 美股 yfinance/API     │
        └───────────────────────────────────────────────┘
```

---

## 二、统一数据约定

- **基准币种：人民币 CNY**。所有金额统一带 `currency` 字段（`CNY` / `USD`）。
- **展示双视图**：原币金额 + 折算人民币，汇率 `fx_rate` 可手动维护或自动获取。
- **时间**：统一按本地时区存储，美股交易时段单独标注。

---

## 三、模块一：日常开销（记账）

### 实体模型
- **账户 Account**：`{ id, name, type(现金/银行卡/支付宝/微信/其他), initial_balance }`
- **交易 Transaction**：`{ id, date, direction(收入/支出), category, amount, currency, account_id, note, tags[], is_recurring, recurring_rule? }`
- **分类 Category**：`{ id, name, type(收入/支出), icon, monthly_budget? }`（预置 + 可自定义）

### 核心功能
- 快速记账（首页主操作，三步内完成一笔）
- 分类 / 账户管理
- 月度、年度收支报表（饼图按分类、折线按月份）
- 分类预算预警（接近/超支提醒）
- 账户余额联动、搜索与筛选
- 周期/订阅支出（房租、会员等 recurring）

---

## 四、模块二：投资（股票为主，A股 + 美股）

### 实体模型
- **证券 Security**：`{ code, name, market('A'|'US'), currency, exchange }`
- **持仓 Position**：`{ id, security_code, shares, avg_cost, current_price?, updated_at? }`
- **交易 Trade**：`{ id, date, action(买入/卖出), security_code, shares, price, fee, currency, account? }`
- **分红 Dividend**：`{ id, date, security_code, amount, currency, tax? }`
- **汇率 FxRate**：`{ date, from('USD'), to('CNY'), rate }`

### 核心计算
- 持仓市值 = `shares × current_price`
- 浮动盈亏（未实现）= `(current_price − avg_cost) × shares − 累计费用`
- 已实现盈亏（来自卖出交易）
- 总收益率、按市场（A/US）汇总、净资产折算 CNY

### A股 vs 美股差异处理
| 维度 | A股 | 美股 |
|------|-----|------|
| 代码格式 | 6 位数字（600519） | 字母（AAPL） |
| 币种 | CNY | USD（需汇率折算） |
| 手续费 | 印花税 + 过户费 + 券商佣金 | SEC 费 + 券商佣金 |
| 结算 | T+1 | T+0 |
| 行情源 | 东财/新浪 | yfinance / Alpha Vantage |

### 核心功能
- 持仓概览（**涨红跌绿**，符合 A 股习惯）
- 交易流水、分红记录
- 个股 / 市场盈亏分析
- 价格更新（手动录入 或 接入 API）

---

## 五、模块三：目标预算

### 实体模型
- **目标 Goal**：`{ id, name, category(装修/旅行/购房/其他), target_amount, current_amount, currency, deadline?, priority, auto_monthly?, linked_source?, note, status }`
- **存入 Allocation**：`{ id, goal_id, date, amount, currency, from(日常结余/投资回款/手动), note }`

### 核心功能
- 创建目标（如装修、旅行、买房首付）
- 进度条 + 达成倒计时
- 每月建议存入 = `(目标金额 − 已存) / 剩余月数`
- 资金来源关联（日常结余 / 投资回款 / 手动存入）
- 多目标排序与优先级管理

---

## 六、总览仪表盘

- **净资产** = 现金账户余额 + 投资市值(CNY) − 负债（可选）
- 本月收支净额
- 投资总浮动盈亏
- 目标总体完成度
- 现金流趋势图

---

## 七、技术选型（已确认）

- **形态**：Web 应用（响应式，移动端优先适配）
- **前端**：React 18 + TypeScript + Vite + Tailwind CSS
- **状态/存储**：Zustand + persist 中间件，底层 IndexedDB（localForage / idb）
- **图表**：ECharts（配置红涨绿跌，符合 A 股习惯）
- **路由**：React Router（/ 仪表盘、/expenses、/invest、/goals、/settings）
- **行情**：接入免费行情 API（见第九节）
- **部署**：先做本地版；架构上为「后续自部署服务器」预留，行情请求统一走可配置 `quoteService` 抽象，切换直连/代理只改一处配置

### 响应式设计规范
- 移动优先（mobile-first），断点 sm/md/lg
- 顶部导航在 < md 折叠为汉堡抽屉菜单
- 图片 `max-w-full` 自动缩放；表格在窄屏包裹横向滚动容器，或降级为卡片列表
- 图表基于容器尺寸自适应（ECharts resize + ResizeObserver）

## 八、行情与汇率接入方案（已确认：统一接口）

### 统一行情源（已定方向）
- **主源：东方财富 push2**，单一接口覆盖 A 股 / 美股 / 港股 / ETF / 指数，无需为美股另接 Yahoo。
  - 通过 `secid` 前缀区分市场：`1.`=沪市、`0.`=深市、`105.`=NASDAQ、`106.`=NYSE、`107.`=美股ETF、`116.`=港股
  - 示例：`https://push2.eastmoney.com/api/qt/stock/get?secid=105.AAPL&fields=f43,f44,...`
  - 价格按接口返回的小数位字段（如 `f59`）还原真实值；美股/港股价格以**原币（USD/HKD）**返回，直接适配双币种模型
  - 注意：免费源美股可能存在延迟（约 15 分钟），个人记账足够；若需实时美股价，后续再接付费源或代理
- **备源：腾讯 gtimg**（`usAAPL` 等），字段更全但浏览器端需代理；作为主源不可用时的降级
- 所有请求收敛到 `quoteService`，内部按 `secid` 规范拼装；切换主/备源或部署形态只改配置

### 汇率（USD→CNY）
- 免费来源：exchangerate.host / open.er-api.com / 央行中间价
- 支持手动维护兜底；每日自动刷新一次并缓存

> 所有外部请求集中在 `quoteService`，切换数据源 / 部署形态不影响业务代码。

## 九、双币种模型（已确认）

- 金额统一带 `currency`（`CNY` / `USD`）
- 维护 `fxRate(USD→CNY)`，自动获取或手动录入
- 展示组件 `<Money>`：原币金额 + 「≈ ¥折算值」
- 汇总类计算（净资产、盈亏）统一折算为 CNY

## 十、已确认的关键决策

1. **应用形态**：Web 应用，响应式、移动端适配（折叠导航 / 图片缩放 / 表格横滚）
2. **股票行情**：接入免费行情 API（A股 东财/腾讯，美股 经代理的 Yahoo）

## 十二、对照市面优秀软件的补充要点（待定稿）

> 参照 钱迹/鲨鱼记账/随手记（记账）、YNAB/网易有钱（预算）、雪球/东财/富途（投资）、
> Personal Capital/Copilot（净资产聚合）。🔴 建议必加 · 🟡 增强 · ⚪ 远期。

### 跨模块 / 应用级
- 🔴 资产负债表 + 负债账户（信用卡/花呗/房贷/车贷，**已确认纳入，用户有车贷**）：净资产 = 资产 − 负债
- 🔴 账户间转账（Transfer）：现金互转、银行→券商入金，避免重复计入收支
- 🔴 隐私保护：应用锁（PIN/生物识别）、本地数据加密
- 🟡 通知/提醒：账单日、预算超支、目标存入、股价预警
- 🟡 自动备份 + 多端同步架构（为自部署预留账号与同步层）
- ⚪ 拍照记账 OCR、自定义仪表盘

### 日常开销
- 🔴 账单导入：支付宝/微信/银行 CSV 解析导入（大幅降低录入成本）
- 🟡 整体月度预算（不止分类预算）+ 预算执行进度
- 🟡 周期/订阅规则引擎（自动生成房租、会员费等）
- 🟡 按商户/标签搜索、资产负债视图

### 投资（股票）
- 🔴 多投资账户：不同券商/币种账户独立记录，持仓按账户聚合；券商账户内闲置现金计入资产
- 🔴 证券类型扩展：股票 + ETF（A/美股 ETF 极常见）+ 可转债（可选）+ 基金（后续），统一为「证券」
- 🔴 公司行动（Corporate Actions）：拆股/合股、送股、分红再投资——不处理会导致份额/成本错乱
- 🔴 汇率折算口径：成本按「交易时点历史汇率」折人民币 vs「当前汇率」——需明确（建议成本以原币记录，净值用当前汇率折算）
- 🟡 费用明细：按市场不同（A股 佣金/印花税/过户费；美股 commission/SEC fee/ADR fee）
- 🟡 基准对比（vs 沪深300 / 标普500）收益率
- 🟡 税后收益（股息税、资本利得税）记录

### 目标预算
- 🟡 目标与月度预算联动：每月需存额自动反映到当月预算
- 🟡 资金来源账户（从哪个现金账户划拨）
- ⚪ 零基预算（YNAB 式 envelope）——进阶，先不实装

> 下一步：将 🔴 项纳入设计基线，再按模块（日常开销 → 投资 → 目标预算 → 仪表盘）逐一定稿。

## 十三、本轮新增确认（2026-10-12）

- **负债账户确认纳入**：用户有车贷，需建模负债账户（本金余额、利率、月供、剩余期数），净资产 = 资产 − 负债。
- **投资录入与计价策略（已确认方向）**：
  - 交易（买入/卖出/分红）为**唯一数据源**，持仓（股数、成本）由交易台账推导，避免「持仓」与「交易」两处录入对不上。
  - 提供「初始化建仓」快捷入口：一次填 股数 + 成本，系统生成一条初始买入记录，满足「手动录入持仓、股数及成本」的诉求。
  - 行情接口（东财 push2）**仅用于取现价做市值计量（mark-to-market）**，绝不写回交易；现价默认自动获取，支持手动覆盖。
  - 成本以**原币**记录，净值用「当前汇率」折算人民币（汇率口径待最终确认）。
  - 公司行动（拆股/送股）：因持仓为推导值，遇拆股可在台账加「调整」事件或修订初始建仓，不会算乱。
- **待模块定稿时再确认**：多投资账户（不同券商/币种）、证券类型扩展范围（先股票+ETF）、费用明细、基准对比、税后收益。
