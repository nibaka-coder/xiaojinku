## 一、设计目标与原则（Apple 极简 / 高级质感）

| 维度 | 规范 |
|---|---|
| **字体** | 系统字体栈：`-apple-system, BlinkMacSystemFont, "SF Pro Display", "PingFang SC", "Helvetica Neue", sans-serif`；标题用中等字重(500–600)，避免过粗 |
| **配色** | 浅色为主、可选深色。中性背景（近白 `#F5F5F7` / 卡片纯白 `#FFFFFF`），文字 `#1D1D1F` / 次级 `#6E6E73`；**单一强调色**见下方决策点 |
| **圆角** | 大圆角语言：卡片 16–20px，按钮/输入框 10–12px，头像/图标 12–999px |
| **阴影** | 极淡分层阴影（`0 1px 3px rgba(0,0,0,.04)`、`0 8px 24px rgba(0,0,0,.06)`），靠留白而非描边分隔 |
| **材质** | 侧边栏 / 顶部栏可用毛玻璃（`backdrop-blur`），半透明 + 细描边 |
| **间距** |  generous 留白：页面边距 24–32px，卡片内边距 20–24px，列表行高 56–64px |
| **动效** | 轻微、顺滑（200–300ms ease-out）；页面切换用淡入+位移，数字变化用滚动/渐变 |
| **数据可视化** | 图表去网格线、去 heavy 描边；饼图/环形用柔和同色系渐变；涨跌遵循 A股 红涨绿跌（仅投资模块） |
| **响应式** | 桌面：左侧固定栏(240px) + 内容区；移动：底部 Tab 栏(4–5 项) + 抽屉式二级菜单 |

## 三、页面级功能设计

### 3.1 日常开销

#### ① 记账（核心录入）
**录入字段（极简，仅必要项）：**
| 字段 | 说明 |
|---|---|
| 金额 | 大数字键盘录入，居中大字号 |
| 类型 | 支出 / 收入（默认支出） |
| **分类** | 复用既有分类体系（餐饮/交通/购物/居住/娱乐/医疗/其他/工资/理财收益…），图标网格选择 |
| **资金来源** | **仅两项：现金 / 信用贷款**（不细化微信、支付宝、银行卡） |
| 日期 | 默认今天，可改 |
| 备注 | 可选，单行 |

**交互要点：**
- 类型切换用 iOS 分段控件；选择后金额区与配色随之变化（支出=主导色，收入=绿色系）。
- 分类选择：图标 + 文字网格，轻点即选，选中态用细环/淡底。
- 资金来源：两个大按钮卡片（现金 / 信用贷款），二选一。
- 支持「连续记账」（记完一笔后保留分类/来源，快速记下一笔）。
- 点历史流水任意一笔可进入编辑/删除。

#### ② 流水
- 按 日 → 月 分组的时间线，左图标+分类，右金额(双视图：原币 + ≈¥折算)。
- 筛选：类型(收/支)、分类、资金来源(现金/信用贷款)。
- 搜索：商户/备注关键词。
- 顶部汇总：本期收入、支出、结余。

#### ③ 统计
- 收支趋势：近 6 月折线/面积图（去网格、柔和填充）。
- 分类占比：本月支出环形图 + 图例列表（金额/占比）。
- 预算执行：整体 + 分类进度条（<80% 正常、≥80% 预警、≥100% 标红）。
- （原 v1 的「报表」页并入此处；原「预算」管理入口移入设置或本页顶部「管理预算」。）

## 四、数据模型调整（相对 v1）

| 项目 | v1 | v2（本次） |
|---|---|---|
| 交易账户 | 多账户（招商银行/微信/支付宝/车贷） | **取消按具体账户录入** |
| 资金来源 | `account_id` 选具体账户 | 新增 `fund_source: 'cash' \| 'credit'`（现金/信用贷款） |
| 分类 | 已具备 | 直接复用，不变 |
| 净资产 | 资产账户汇总 − 负债账户 | **现金余额 − 信用贷款负债 − 长期负债(车贷)** |
| 信用贷款负债 | 无 | 所有「资金来源=信用贷款」的支出自动累计为负债；还款操作减少负债 |

**资金来源对账模型（建议方案，见决策点②）：**
- **现金**：你实际拥有的钱（银行/微信/支付宝聚合，不再区分）。支出现金 → 现金余额减少；收入 → 现金余额增加。
- **信用贷款**：刷信用卡/花呗等信用额度消费。该类支出 → 信用负债增加；「信用还款」（从现金还） → 信用负债减少、现金减少。
- **长期负债**（车贷等）仍作为独立负债账户，单独计入净资产，不受日常录入影响。

> 这样既能满足你「只区分现金/信用贷款、不细化到具体卡」的诉求，又能保证净资产算得对。
