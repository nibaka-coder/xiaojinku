# 小金库 · 投资管理模块设计方案（待确认）

> 状态：设计稿，待用户确认关键决策点后实施
> 关联：v2 导航已预留「投资管理」一级（持仓总览 / 交易记录 / 行情）、概览页「投资情况概览」目前为占位
> 已固化方向（来自历史确认）：交易台账为唯一数据源、持仓由交易推导、行情仅取现价做市值（mark-to-market）；覆盖 A股/美股/ETF/港股；红涨绿跌（仅投资模块）

---

## 一、目标与范围

- 让首页「投资情况概览」从占位变为**真实数字**：持仓市值、累计盈亏、本年/区间涨跌。
- 支持手动录入持仓、买卖、分红，**对照行情取现价衡量资产**。
- 不重新发明账户体系：投资资金视为**独立证券账户**，不与日常开销的现金流耦合（详见决策点③）。
- 三币种：A股/ETF 为 CNY，美股为 USD，港股为 HKD；所有汇总统一折 CNY。USD 用 `settings.fxRate`(USD→CNY)，HKD 用 `settings.hkdRate`(HKD→CNY)，二者独立维护（港股行情东财 116. 返回 HKD，不可套用 USD 汇率）。

## 二、数据模型（新增，独立于日常开销）

### 2.1 证券 `Security`
| 字段 | 说明 |
|---|---|
| `id` | 内部主键 |
| `code` | 代码，如 `600519`、`AAPL` |
| `name` | 名称，如 `贵州茅台` |
| `market` | `ashare` / `us` / `hk` / `etf` |
| `currency` | `CNY` / `USD` / `HKD`（A股/ETF=CNY，美股=USD，港股=HKD） |
| `secid` | 东财格式，行情主键（见 §三）：A股 `1.600519`/`0.xxxxxx`、美股 `105.AAPL`、港股 `116.xxxxx` |
| `manualPrice?` | 手动维护的现价（行情取不到时的兜底） |
| `note?` | 备注 |

### 2.2 投资交易台账 `InvestTxn`
| 字段 | 说明 |
|---|---|
| `id` | 主键 |
| `security_id` | 关联证券 |
| `type` | `open`(建仓) / `buy`(买入) / `sell`(卖出) / `dividend`(分红) |
| `datetime` | 成交时间 |
| `shares` | 股数（分红可为 0） |
| `price` | 成交单价（原币） |
| `fee` | 费用（原币，默认 0） |
| `amount` | 成交金额 = `shares*price + fee`（原币，卖出/分红为负向流入） |
| `currency` | 原币 |
| `note?` | 备注 |

> **持仓推导（不存库）**：按 `security_id` 聚合所有台账 → 当前股数、累计投入成本、分红累计；现价取自行情或 `manualPrice` → 市值与浮动盈亏。

## 三、行情方案（收敛到 `quoteService`）

- **优先**：东方财富 push2 统一接口，一个接口覆盖 A股/美股/ETF/港股（secid 前缀：`1.`/`0.`=A股、`105.`/`106.`/`107.`=美股、`116.`=港股）。美股约 15 分钟延迟。
- **备源**：腾讯 `qt.gtimg.cn` 文本行情，作回落。
- **降级**：两者都取不到时，使用证券的 `manualPrice`（手动填价），保证离线/被墙也不崩。
- **接入方式**：先探测东财 push2 的 CORS 是否放行；若放行直接 `fetch`，否则走 JSONP（动态 script，跨域友好，且 `file://` 离线也能用）。所有请求只经 `quoteService` 一处。
- **刷新时机**：默认**手动点「刷新行情」**（不自动拉，省流量、且离线可控）；可后续加「打开时自动刷新」开关。

## 四、页面结构（沿用 v2 预留路由）

| 路由 | 页面 | 内容 |
|---|---|---|
| `/invest/holdings` | 持仓总览 | 证券卡片列表（名称/代码/市场、股数、成本价、现价、市值、≈¥折算、盈亏额、盈亏率）；顶部汇总（总市值 / 总投入 / 总盈亏）；点卡片进个股详情 |
| `/invest/security/:id` | 个股详情 | 关键指标 + 该证券交易台账 + 「记一笔交易」入口 |
| `/invest/trades` | 交易记录 | 全部投资台账时间线（建仓/买入/卖出/分红），可按证券/类型筛选、可删除 |
| `/invest/add` | 新增交易 | 选/新建证券、类型、股数、单价、费用、日期、备注 |
| `/invest/quote` | 行情 | 搜索/添加证券，显示东财现价/涨跌/市值，「加入持仓」 |

- 移动端：投资管理进入后顶部用分段控件切换（持仓/记录/行情），与日常开销一致。
- 涨跌配色：**红涨绿跌**（仅投资模块，与日常开销区分）。

## 五、概览联动（首页「投资情况概览」）

- 有持仓时显示：**持仓市值 ¥X · 累计盈亏 ¥Y(±z%) · 本年涨跌**，点「去投资管理」进持仓总览。
- 无持仓时仍为引导占位。
- 投资市值是否并入顶部「净资产」由**决策点②**决定。

## 六、数据持久化

- `securities`、`investTxns` 加入 zustand persist（同 IndexedDB），`exportData`/`importData` 同步增补，保证导入导出完整。
- 种子数据：默认塞 **1 个 A股示例（贵州茅台 + 一笔建仓）+ 1 个美股示例（AAPL + 一笔建仓）**，便于首开即见效果（可在设置「清空恢复示例」）。
