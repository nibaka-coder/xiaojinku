# 模块一 · 日常开销（定稿）

> 状态：已定稿（2026-10-12）｜ 关联：主方案 `design/小金库应用设计方案.md` 第十三节

## 1. 模块定位
记录个人日常资金流动（收入 / 支出 / 账户间转账），是整套「小金库」的**数据基座**：
账户、分类、交易模型被投资模块（券商账户 / 入金出金）与目标预算模块（资金来源账户）复用。

## 2. 数据模型

### 2.1 账户 Account（全局实体，跨模块复用）
```ts
type AccountCategory = 'asset' | 'liability';

interface Account {

  due_day?: number;           // 还款日
  remaining_terms?: number;   // 剩余期数
  archived: boolean;
  created_at: string; updated_at: string;
}
```

## 3. 核心计算规则

### 3.1 账户余额（派生，不存储）
```
net_flow(txn, acc):
  income   & acc == account_id       -> +amount
  expense  & acc == account_id       -> -amount
  transfer & acc == account_id(from) -> -amount
  transfer & acc == to_account_id    -> +amount

sign(acc) = acc.category == 'asset' ? +1 : -1   // 负债余额=欠款：流入减少、流出增加
balance(acc) = initial_balance + Σ net_flow * sign(acc)
```
校验示例：车贷初始 100000，月供从银行转入车贷 3000 → 车贷余额 97000 ✓；
信用卡消费记为 expense（账户=信用卡，负债）→ +amount（欠款增加）✓。

### 3.2 净资产
```
净资产 = Σ(资产账户余额, 折 CNY) + 投资市值(折 CNY, 投资模块提供) − Σ(负债账户余额, 折 CNY)
折算：USD 余额 × fxRate(USD→CNY)
```

### 3.3 月度收支
```
某月：income = Σ 收入(CNY)，expense = Σ 支出(CNY)，net = income − expense
（转账不计入收支）
```

### 3.4 分类汇总 / 趋势 / 环比同比
- 分类占比：按 category 汇总支出(CNY) → 饼图
- 趋势：按自然月聚合 income / expense / net → 折线
- 环比：本月 vs 上月；同比：本月 vs 去年同月

### 3.5 预算执行
```
对月份 M、分类 C（或整体）：
spent   = Σ M 内该分类支出(CNY)
budget  = Budget.monthly_amount
remaining = budget − spent
ratio   = spent / budget
预警：ratio ≥ 0.8 提醒；ratio ≥ 1 超支（红）
```

## 4. 页面与交互（响应式）
1. **记账页**：金额大键盘 + 类型切换(支出/收入/转账) + 账户/分类/商户/日期/标签；转账显示「从→到」；支持连续记账。手机优先大按钮。
2. **流水列表**：按日分组，筛选(账户/分类/类型/标签/区间/金额) + 搜索(商户/备注)；手机卡片、窄屏表格横滚；点击编辑/删除。
3. **账户页**：资产/负债分区，显示余额(原币+折算)；新增/编辑/归档；负债显示利率/月供/剩余期数；转账入口。
4. **分类管理**：收/支列表，图标/颜色/月度预算/排序/二级分类。
5. **预算**：整体 + 分类预算进度条（红绿 / 超支预警）。
6. **报表**：收支趋势折线、分类占比饼图、自定义区间、环比同比（ECharts；此处用主题色，红涨绿跌仅用于投资模块）。
7. **账单导入**：上传支付宝/微信/银行 CSV → 字段映射 → 预览 → 确认导入（按 external_id 去重）。
8. **设置**：应用锁(PIN/生物识别)、数据导出/导入(JSON)、汇率维护、默认值。

## 5. 与其他模块衔接
- **账户全局复用**：投资模块的券商账户(brokerage)、目标预算的资金来源账户，均复用本模块 Account；券商「入金/出金」= 银行↔券商 的 transfer。
- **币种统一**：日常以 CNY 为主，保留 currency 字段（境外消费可用 USD）；所有汇总按 fxRate 折 CNY，沿用全局双视图。
- **横切能力**：隐私锁、提醒、备份为全局能力，在设置 / 后台实现，不限于本模块。

## 6. 范围与待定
- **v1 包含**：账户(资产+负债)、分类、交易(收/支/转账)、流水、报表、月度+分类预算、应用锁、JSON 备份。
- **v1 建议包含**：账单 CSV 导入、周期/订阅规则。
- **可后置**：二级分类、高级环比同比、拍照记账(OCR)。

## 7. 待投资 / 目标模块定稿时确认
